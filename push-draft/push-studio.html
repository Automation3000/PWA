Firebase Cloud Messaging (FCM) Integration Guide
Architectural Guide
Did You Know? Your Tabreed PWA is already connected to Google Chrome's native Web Push network (FCM) using the 100% free VAPID protocol. You do not need Firebase or third-party paid accounts for Chrome/Android push alerts to work. However, if you want to connect a dedicated Firebase Project, follow the steps below:
Step 1: Create a Firebase Project

1. Open console.firebase.google.com.
2. Click Add Project > Name it (e.g. tabreed-automation).
3. Add a Web App (</>) to get your Firebase Config keys.

Step 2: Generate Web Push Certificate (VAPID Key)

1. In Firebase Console, go to Project Settings (⚙️) > Cloud Messaging tab.
2. Under Web configuration > Web Push certificates, click Generate key pair.
3. Copy the generated Key (This replaces your VAPID Public Key).

Step 3: Frontend Client Integration (firebase-messaging-sw.js)

Import Firebase scripts in your Service Worker and initialize messaging: 

importScripts('https://www.gstatic.com/firebasejs/9.22.0/firebase-app-compat.js');
importScripts('https://www.gstatic.com/firebasejs/9.22.0/firebase-messaging-compat.js');

firebase.initializeApp({
  apiKey: "AIzaSy...",
  projectId: "tabreed-automation",
  messagingSenderId: "..."
});

const messaging = firebase.messaging();
messaging.onBackgroundMessage((payload) => {
  self.registration.showNotification(payload.notification.title, {
    body: payload.notification.body,
    icon: '/icon-192.png'
  });
});
Step 4: Server Dispatch via Firebase Admin SDK

On your Node backend, install firebase-admin and send push alerts directly: 

import admin from 'firebase-admin';
// Send notification to device token
await admin.messaging().send({
  token: deviceToken,
  notification: { title: "Tabreed Alert", body: "Chiller 04 status updated" }
});
Comparison: Self-Hosted Web Push vs Firebase FCM
✅ Current Self-Hosted Engine:
  • 100% Free, zero external limits
  • Runs completely inside this repo
  • No Google Cloud billing account needed
  • Works directly in Chrome, Android, Edge, iOS
ℹ️ Firebase FCM:
  • Requires GCP project setup
  • Topic subscription management in cloud
  • Dashboard analytics in Firebase Console
  • Best for large multi-platform enterprise teams
