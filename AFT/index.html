Air File Transfer Architecture

Airgapped Optical QR Code Data Transfer

Air File Transfer (AFT) allows secure, bidirectional transmission of arbitrary files across strictly isolated (airgapped) industrial systems, SCADA environments, and field tablets without touching any physical network, Wi-Fi router, Bluetooth stack, or USB storage device.

100% Airgap Compliant

Zero network packets. Data travels exclusively via optical light photons from display to camera lens.

GZIP Level 9

High compression reduces payload size up to 85% for lightning-fast transmission cycles.

Hardware Scanning

Leverages native GPU-accelerated BarcodeDetector and ZBar WASM for seamless 60fps decoding.
